# Con Est

Painting estimating app for First Class Finishes: load PDF plans, auto takeoff, quote at your rates, track jobs and schedule painters.

Install on Android: open the site in Chrome, then menu ⋮ → **Install app** (or **Add to Home screen**).
Install on iPhone: open in Safari, Share → **Add to Home Screen**.

Everything is saved on the device (browser storage). Use Job… → Copy backup to move a job between devices.

Hosted with GitHub Pages from this folder. After changing `index.html`, bump `VERSION` in `sw.js`.

## Editing

The app source is `src/con-est.src.html`. After editing it, run `python3 tools/build.py` and bump `VERSION` in `sw.js`.
