# Gem Crab Helper

A RuneLite plugin for the Gemstone Crab. It helps you while you play; it does not click or play for you.

- Outlines the crab and shows its HP % above it (HP updates while its health bar is showing)
- Notifies you when a crab appears, when the one you were fighting disappears, and when you stop attacking it
- Session panel: crabs done, time, combat XP gained and XP per hour

Everything can be switched on or off in the plugin's settings. If the NPC name in game isn't exactly `Gemstone Crab`, change **Crab name** in the settings.

## Try it

Needs Java 11+ and Gradle. Open this folder in IntelliJ (or run from a terminal) and run `GemCrabPluginTest` in `src/test/java`. That starts RuneLite with the plugin loaded. Turn on developer mode if RuneLite asks.

To share it with other players, submit it to the RuneLite Plugin Hub: https://github.com/runelite/plugin-hub
